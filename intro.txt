Bienvenido a mi repo!

Lista de comandos:

git init : Inicializa git en el proyecto

git remote add origin <enlace_repo> : Conecta con el repositorio que necesito vincular. Colocar enlace sacado de la página principla cuando se crea un nuevo repo

git remote -v : Ver a qué está vinculado

git add intro.txt : Registra el archivo para eventualmente enviarlo al grupo

git status: Qué archivos están registrados y cuáles nuevo

git add . : Registra todos los archivos creados que estén sin registrados

git commit -m "tesis 1" : Crea commits

git log : Ver el registro de comandos creados -> número en amarillo es el id del commit para no confundir con otros

git push origin master : Sube todos los archivos para vincularlos

git commit -m "tesis 2" : Registra los cambios hechos para subir -> luego repetir "git push origin master"

git checkout : para volver a algún backup anterior y retomar desde ahí o arrancar algo nuevo desde ese punto.
